# autoparts

Маркетплейс автозапчастей (by autolick): одностраничное мобильное приложение
на иврите (RTL) + REST API на Node.js.

## Структура репозитория

```
index.html            # оболочка приложения: дизайн-токены, вёрстка, стили
app.js                # всё приложение: экраны, навигация, работа с API
backend/              # REST API (Node.js + Express + SQLite) + раздача фронтенда
  src/                # сервер, схема БД, сиды, роуты и middleware
  README.md           # полная документация API
```

## Быстрый старт

```bash
cd backend
npm install
cp .env.example .env
npm run seed     # демо-продавцы, товары и кросс-номера
npm start        # http://localhost:4000
```

Сервер раздаёт и фронтенд, так что после `npm start` всё доступно по одному адресу:

| Адрес | Что это |
|---|---|
| http://localhost:4000/ | приложение целиком |
| http://localhost:4000/api/health | проверка, что API жив |

Демо-логин продавца: `hertzel@example.com` / `demo1234`.

## Экраны

Приложение единое, переключение — нижним «островным» навбаром; чёрная кнопка `+`
создаёт позицию (только для продавца).

| Экран | Что делает |
|---|---|
| Главная | герой, поиск по названию или мактim, быстрые подсказки, категории |
| Поиск | список результатов, фильтр по состоянию (оригинал / аналог / б/у), карточка раскрывается по нажатию |
| Карточка детали | мактim того же узла, сворачиваемая карточка продавца, **аналоги** — те же детали у других продавцов |
| Мой склад | плитки статистики, свои позиции, редактирование и удаление |
| Новая позиция | форма с мактom, взаимозаменяемыми номерами, состоянием, ценой и количеством |
| Сообщения | список бесед и переписка с заявкой на заказ |
| Профиль | вход и регистрация — отдельно для покупателя и продавца |

## Ключевые доменные решения

**Мактim обязателен, но уникален только внутри продавца.** Одну и ту же деталь
предлагают несколько продавцов — на этом и стоит сравнение цен. Поэтому
`UNIQUE (seller_id, part_no)`, а не глобальная уникальность.

**Аналоги ищутся по пересечению номеров.** Если две позиции делят хотя бы один
взаимозаменяемый номер (или совпадают по макту), они показываются друг другу как
аналоги, отсортированные по цене.

Полное описание эндпоинтов — в [`backend/README.md`](backend/README.md).
