# autoparts

Маркетплейс автозапчастей (by autolick): одностраничное мобильное приложение
на иврите (RTL) + REST API на Node.js.

## Структура репозитория

```
index.html            # оболочка приложения: дизайн-токены, вёрстка, стили
app.js                # всё приложение: экраны, навигация, работа с API
backend/              # REST API (Node.js + Express + SQLite) + раздача фронтенда
  src/                # сервер, схема БД, сиды, роуты и middleware
  README.md           # полная документация API
```

## Быстрый старт

```bash
cd backend
npm install
cp .env.example .env
npm run seed     # демо-продавцы, товары и кросс-номера
npm start        # http://localhost:4000
```

Сервер раздаёт и фронтенд, так что после `npm start` всё доступно по одному адресу:

| Адрес | Что это |
|---|---|
| http://localhost:4000/ | приложение целиком |
| http://localhost:4000/api/health | проверка, что API жив |

Демо-логин продавца: `hertzel@example.com` / `demo1234`.

## Экраны

Приложение единое, переключение — нижним «островным» навбаром; чёрная кнопка `+`
создаёт позицию (только для продавца).

| Экран | Что делает |
|---|---|
| Главная | герой, поиск по названию или макту, быстрые подсказки, фильтр-шторка по отделам и по машине |
| Поиск | список **макатов** (не объявлений), под ними «может подойти» и найденные поставщики; фильтр по состоянию |
| Макат | шапка со всем, что известно о детали, под ней — карточки поставщиков с их ценами, дешевле сначала |
| Карточка предложения | то, что ввёл конкретный поставщик: его цена, наличие, контакты, ссылка на его страницу и на всех поставщиков этого маката |
| Страница поставщика | кто это, что он поставляет, адрес и часы, и вся его полка |
| Мой склад | плитки статистики, свои позиции, редактирование и удаление |
| Новая позиция | форма с мактom, взаимозаменяемыми номерами, состоянием, ценой и количеством |
| Сообщения | список бесед и переписка с заявкой на заказ |
| Профиль | вход и регистрация — отдельно для покупателя и продавца; у продавца здесь же данные «о себе», которые видит покупатель |

## Ключевые доменные решения

**Мактim обязателен, но уникален только внутри продавца.** Одну и ту же деталь
предлагают несколько продавцов — на этом и стоит сравнение цен. Поэтому
`UNIQUE (seller_id, part_no)`, а не глобальная уникальность.

**Везде выдаются макаты, а не объявления.** Одна деталь у четырёх продавцов —
это один макат и четыре цены внутри него, иначе полка и поиск повторяют одно и
то же четыре раза. Каталог макатов собирается из объявлений и их кросс-номеров
при каждой записи, id макатов при пересборке сохраняются.

**Цена показывается как «от».** Средней цены не существует ни у кого на руках:
минимум — это то, что действительно можно купить, а среднее стоит рядом
подсказкой, чтобы 120 ₪ за деталь с разборки не читались как цена новой.

**Поставщик — тоже ответ на поиск.** Поиск ищет и по имени, городу и профилю
поставщиков; у каждого есть страница с контактами и всей его полкой, а данные
«о себе» он заполняет в кабинете.

Полное описание эндпоинтов — в [`backend/README.md`](backend/README.md).

## Развернуть в интернете

Чтобы прототип жил по своему адресу и открывался с телефона в любой момент,
а не только пока включён ваш компьютер.

В репозитории есть `render.yaml` — готовое описание сервиса. На
[render.com](https://render.com): **New → Blueprint**, выбрать этот репозиторий,
ветку `claude/hello-pkving`, подтвердить. Секрет `JWT_SECRET` Render сгенерирует
сам, остальное уже прописано. Через несколько минут появится адрес вида
`https://autoparts.onrender.com`.

Открыть его на iPhone в Safari → **Поделиться → На экран «Домой»**. Приложение
встанет иконкой и будет открываться на весь экран.

**Про бесплатный тариф.** Диск временный: при каждом передеплое база
обнуляется — сервер это переживает и сам наполняет каталог демо-данными при
старте, так что пустого экрана не будет, но добавленные вручную позиции и
переписка пропадут. Сервис засыпает после ~15 минут без запросов, первое
открытие после сна занимает около минуты. Для «потрогать» это нормально; для
реальных продавцов нужен платный тариф с постоянным диском или PostgreSQL.
