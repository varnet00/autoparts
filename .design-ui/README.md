# Предложения по внутренним экранам

Макеты внутреннего интерфейса — то, что предлагается изменить,
а не то, что уже работает в приложении. Статичные, для просмотра.

- `Main.dc.html` — карточка предложения поставщика
- `Position.dc.html` — экран маката с фильтром состояния на предложениях
- `Home.dc.html` — главный экран с историей поисков
- `Stock.dc.html` — кабинет поставщика компактными строками
- `Cards.dc.html` — лист состояний карточки маката
- `canvas.json` — раскладка артбордов и заметки

Токены и компоненты взяты один-в-один из `index.html`: цвета `:root`,
классы `.card` (радиус 20), `.tag`, `.chip`, `.btn`, `.num`, `.price`,
`.label`, шкала `--fs-*` и `--s*`, тап 44 px, иконки в сетке 24 со
stroke-width 2.2. Ничего не округлял к сетке 4/8 — значения ровно те же,
иначе макет не сойдётся с приложением.

Артборды генерируются `gen.py` (общие куски — шапка, док, теги,
карточки — в `_ui.py`), чтобы геометрию можно было править числами.

Собранный канвас в репозиторий не кладём — он пересобирается из этих
файлов скиллом design (`seed-canvas.mjs`).
