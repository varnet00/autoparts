# Направления заставки

Исходники дизайн-канваса с концепциями заставки. Пять направлений,
у каждого ключевой кадр (артборд 390×844) и раскадровка движения.

- `Main.dc.html` / `MainBeats.dc.html` — A · Разнос
- `Scan.dc.html` / `ScanBeats.dc.html` — B · Диагностика
- `Tread.dc.html` / `TreadBeats.dc.html` — C · Протектор
- `Night.dc.html` / `NightBeats.dc.html` — D · Ночная смена
- `Ignition.dc.html` / `IgnitionBeats.dc.html` — E · Заводка
- `canvas.json` — раскладка артбордов и заметки на канвасе

Артборды генерируются скриптами `gen1.py`, `gen2.py`, `gen3.py`
(общие куски — знак, шрифты, обёртка страницы — в `_common.py`),
чтобы геометрию можно было править числами, а не руками в разметке.
Токены взяты из `index.html`: #dd6612, фон #efece8, чернила #16140f,
приглушённый #8b847b, линия #e4dfd8, Heebo и IBM Plex Mono.

Собранный канвас в репозиторий не кладём — он пересобирается из
этих файлов скиллом design (`seed-canvas.mjs`).
